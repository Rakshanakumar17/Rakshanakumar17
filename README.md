## 🚀 Featured Projects

### 📊 1. E-Commerce Sales & Customer Intelligence Dashboard

The E-Commerce Sales & Customer Intelligence project is an end-to-end analytics project using the Global Superstore dataset to explore sales performance, profitability, customer contributions, product categories, and regional business trends. The project begins with dataset exploration and preparation using Python and Pandas, followed by data cleaning, exploratory data analysis, and visualization. Microsoft Excel supports data preparation, while Tableau is used to create an interactive dashboard that presents important business metrics and comparisons. The analysis includes total sales, total profit, order volume, customer contributions, product category performance, regional performance, and monthly sales trends. This project helped me understand how to move from a raw dataset to a structured analytical workflow and communicate business findings through visual storytelling. It also strengthened my understanding of how analytical results can help businesses identify high-performing categories, evaluate regional performance, and investigate customer trends.

**Technologies:** Python, Pandas, NumPy, Google Colab, Microsoft Excel, Tableau, and Exploratory Data Analysis.

### 🔄 2. E-Commerce Sales ETL Pipeline

The E-Commerce Sales ETL Pipeline demonstrates how data can be extracted from a CSV file, transformed using Python and Pandas, and loaded into a MySQL database for further analysis. The project processes 5,000 sales records and prepares the data by converting order dates into datetime values, extracting order year and month, checking data quality, and validating important numerical fields. The transformed data is loaded into a database named `ecommerce_etl`, and SQL queries are used to verify the imported records and investigate revenue by product category, region, and payment method. I also performed validation checks on order IDs, missing values, duplicate records, and revenue calculations to understand the importance of consistency between source data and database records. This project provided practical experience with ETL fundamentals, data preparation, relational database loading, SQL-based business analysis, and the investigation of rounding differences during validation. It also introduced me to the importance of building reliable and repeatable data workflows.

**Technologies:** Python, Pandas, MySQL, SQL, Google Colab, and CSV.

## 🔍 My Data Analytics Workflow

When I work on a data analytics project, I begin by understanding the objective and identifying the questions that the analysis should answer. I then inspect the dataset to understand its structure, column names, data types, and overall quality. During data preparation, I check for missing values, duplicate records, inconsistent formats, and invalid values, and transform the data where necessary. After preparing the dataset, I perform exploratory data analysis using Python, Pandas, SQL, or Excel to summarize values, compare categories, examine trends, and investigate patterns. I then create visualizations and dashboards using Power BI or Tableau to communicate the results clearly. Finally, I document the workflow, validate important calculations, summarize the findings, and identify opportunities for further analysis. I believe this structured approach helps improve the reliability, clarity, and usefulness of analytical work.
